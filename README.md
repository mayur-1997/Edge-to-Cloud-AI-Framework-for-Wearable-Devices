This project focuses on utilizing an existing wearable device equipped with sensors and Edge AI capabilities. The goal is to integrate the device with a cloud platform for data storage, model training and performance optimization. Sensor data will be processed locally on the device for low-latency responses, while the cloud will handle large-scale data aggregation, retraining, and analytics. The system aims to enable efficient edge-to-cloud collaboration for real-time monitoring, adaptive learning, and improved accuracy. Applications include health tracking, activity recognition, and environmental sensing, demonstrating a complete end-to-end Edge AI framework.
